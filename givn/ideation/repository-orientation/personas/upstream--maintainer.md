# Persona: Upstream project maintainer

New: upstream--maintainer — authority boundary: accepts or rejects contributions and sets the upstream project's direction and licence.

This persona is conditional: it applies only if the benchmark leads to a contribution.

## Stable core

- Role: The maintainer of an existing open-source code-knowledge project that may receive Ortsinn's capabilities as a contribution.
- Authority boundary: Reviews and accepts or rejects contributions; sets architecture, language, and licence; can require changes before merge.
- Evaluation capability: Can judge fit with the upstream architecture, test quality, maintenance burden, and licence compatibility.
- Own vocabulary: contribution, merge request, upstream, MIT, TypeScript, maintenance burden.
- Success criterion: An accepted contribution that closes a measured gap without raising the upstream maintenance burden.
